# 温馨猫小屋 · 抖音适配版

AppID：ttd124a7994f5df64502。

这是微信稳定版的独立抖音移植项目。原微信项目未修改。当前已完成代码适配与本地检查，尚未完成抖音开发者工具、真机和线上后端联调，不能直接作为已上线版本提交。

## 导入
用抖音开发者工具导入本目录，选择普通小游戏引擎。画面、40类猫咪、真实音效、成长规则及双人互动继续沿用原项目。默认连接在线后端；未配置地址会明确提示，不会假装保存成功。

只想本机查看画面时，可以暂时将 config.js 的 cloudEnv 改为空字符串。此时是单机体验，不支持真实登录、跨手机共养、赠送和 AI 回复，不能据此判断线上功能已完成。发布前恢复 douyin-http。

## 在线后端（需要部署）
server/ 提供独立 Node HTTP 服务和 Dockerfile，默认监听8000端口。运行在已取得腾讯云开发数据库和存储服务权限的可信服务环境。wx-server-sdk 仅在服务端使用，抖音客户端不直接调用微信云函数。不能仅把 server 文件夹上传成微信事件云函数就当成 HTTP 服务。

服务端环境变量：
- DOUP_APP_SECRET：抖音后台本应用密钥，仅服务端保存。
- DOUP_SESSION_SECRET：至少32位随机高强度签名密钥，仅服务端保存。
- DOUP_CLOUD_ENV：服务端有权限访问的腾讯云开发环境。
- PORT：可选，默认8000。

使用平台托管身份/服务端凭据授予数据库、对象存储权限，禁止将腾讯云密钥打入游戏包。部署和权限开通可能产生费用，按实际控制台套餐核实。

创建 dy_users、dy_rooms、dy_invites 三个集合，客户端全部不可读写，只有服务端访问。该版使用独立集合和抖音身份，不与微信房间自动互通，也不迁移微信创世屋数据。

服务暴露 HTTPS 根路径后，在抖音后台配置合法 request 域名，并将 config.js 的 apiBaseURL 填为该 HTTPS 地址。图片临时地址还需按平台要求配置图片下载域名。AI仍由服务端提供，需验证部署环境是否支持原混元能力和额度，未验证前不能声称聊天已连通。

## 创世屋初始化（上线前必须完成）
新集合是空的，无法自动出现原微信创世屋。部署者需在可信服务端用本人抖音验证身份初始化创世屋，执行 createRoom 后执行 nurseryRoom 激活40品种池，再开放用户入口。初始化尚未在真实环境完成；不要让第一位随机访客代替管理员初始化，也不要手工伪造用户身份。

## 发布前检查
至少两台手机/两个账号验证：登录、首次入口、创世屋初始化、建屋、领养、公母和品种、成长、共养邀请、赠猫领取、解除共养/寄养、隐私照片和留言权限、音频、前后台恢复、分享参数，以及 AI 聊天。

当前广告ID为空，不展示广告入口，也没有广告收益。广告需后续使用抖音广告位接入并真机验证。

原微信文字备份的文件选择/分享接口在抖音上可能不支持；已保留能力检测，不能假定跨平台文件导入可用。小游戏分享卡也需以抖音真实客户端表现为准。

## 本地验证
npm test
npm run check

自动测试覆盖沿用的玩法、隐私和新登录传输逻辑；画面使用 Canvas 本地渲染检查。没有进行线上凭据调用、后端部署或抖音真机测试。

## 抖音容器的跨云连接补充
本版已增加服务端显式读取腾讯云凭据的初始化。抖音云的 SERVICE_ID、CLOUD_ENV 保持平台默认；新增 DOUP_CLOUD_ENV 填腾讯云环境ID，并填写 TENCENTCLOUD_SECRETID、TENCENTCLOUD_SECRETKEY。可选 TENCENTCLOUD_SESSIONTOKEN 用于临时凭据。只能在服务端环境变量/密钥管理中配置，不能发到聊天或提交仓库。使用仅能访问目标云开发环境的专用身份；具体权限需在目标账号配置并联调，代码检查不能证明权限已开通。

接口支持 POST /api/home；测试地址加 /api/home 后填入前端 apiBaseURL。访问控制授权该路径。GET /api/health 仅报告进程运行，不证明数据库和AI已连通。默认域名限测试，正式调用需按抖音云配置合适的调用方式。

独立集合 dy_users、dy_rooms、dy_invites 以及创世屋仍需初始化。请勿把抖音环境ID填进腾讯云环境参数。当前版本尚未部署到真实抖音容器，不保证目标环境的 wx-server-sdk / AI 兼容性，必须以日志和双账号联调为准。
